About

This is a Minecraft-inspired project I started while learning Python and experimenting with game development.

The project was created with significant AI assistance. Some parts of the code may be messy, inefficient, or poorly designed, and the current version contains many bugs and unfinished features.

I'm publishing the project on GitHub as both a playable experiment and a record of its development. I plan to return to the project and continue improving it.

Known Issues

The current alpha version contains many known and unknown bugs.

Some examples:

World Generation

Every time the game is launched, the same map is generated instead of generating a new world.

Block Interaction

Breaking or placing a block does not always affect the world as expected.

Underground Rendering

When digging underground, most of the underground area appears completely hollow except for caves. Breaking a block in this area can cause nearby blocks to suddenly render.

Definitely Real Bug

If you press Z at exactly 67,416,156 FPS while looking at the northern equator of Pluto, one block explodes.

This is a completely serious and definitely reproducible issue.
